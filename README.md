## Preserving History, Connecting It to the Future ✨

**QUDUS** is a cultural and digital preservation project that bridges **heritage and technology**.  
It is dedicated to safeguarding the history of **Al-Aqsa Mosque in particular, and Jerusalem in general**, while presenting it through a modern.

The project brings together:
- Historical artifacts and collectibles related to Jerusalem and Al-Aqsa
- Artistic works by Palestinian artists inspired by the same subject
- Periodic exhibitions open to visitors
- An innovative feature that allows visitors to preserve selected items as **3D-printed models**

QUDUS aims to transform cultural memory into an accessible, living experience — one that can be explored, preserved, and re-imagined.
